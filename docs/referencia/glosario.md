# Glosario

| Término | Significado |
|---|---|
| **DPC** | Plan posconsumo de envases de plaguicidas. Prefijo de los códigos de expediente. |
| **Titular** | Persona jurídica (identificada por NIT) responsable del plan. Puede tener varios expedientes. |
| **Expediente** | Unidad de seguimiento (`DPC0004`, `DPC0089-00`, `DPC0086-00-2014`). En la interfaz se le llama “empresa”. |
| **Uso 1** | Envases de plaguicidas de uso agrícola, veterinario, de salud pública o industrial. Meta sobre lo puesto en el mercado. |
| **Uso 2** | Uso doméstico. Meta incremental sobre una base y cobertura poblacional. |
| **Periodo de recolección** | Año al que corresponden las cantidades. |
| **Año de revisión del informe** | Año en que la autoridad revisó el informe. Independiente del periodo (suele ser periodo + 1). |
| **Puesta en el mercado** | kg de producto que la empresa puso en el mercado en el periodo (Uso 1). |
| **% meta** | Porcentaje de lo puesto en el mercado que debe recolectarse (Uso 1). |
| **Base de la meta / % incremento** | Uso 2: la meta del periodo es la base aumentada en el % de incremento. |
| **Vigencia de seguimiento / vigencias posteriores** | Cantidad validada en el año del seguimiento o en años siguientes. |
| **Abonada vigencia posterior** | Cantidad reconocida en una vigencia posterior; suma al total validado del registro, no al consolidado. |
| **Desuso** | Plaguicidas en desuso generados y validados (kg). |
| **Cobertura** | Uso 2: población atendida por puntos fijos (50 000 hab. c/u) y campañas (100 000 hab. c/u) frente a la meta del periodo. |
| **Operador logístico** | Entidad que recolecta y transporta los residuos (Campo Limpio, Bioentorno, COLECTA, REPCO, Cierra el Ciclo…). |
| **Gestor** | Planta que trata o dispone los residuos (celda de seguridad, incineración, coprocesamiento, aprovechamiento). |
| **Mecanismo de recolección** | Punto de recolección o centro de acopio de un operador. |
| **Certificado de gestión** | Documento con el que el gestor certifica al operador las entregas de residuos tratadas. En el sistema, una fila por entrega. |
| **Gestión global / individual** | Si los certificados de un operador se comparten entre sus empresas (global) o cada uno es de una sola empresa (individual, COLECTA). |
| **Proyección** | Meta proyectada de una empresa para una vigencia. |
| **Seguimiento** | Registro anual de la autoridad sobre un expediente: Iniciales, Indicador, Rezago u Otros. |
| **CT** | Concepto técnico. |
| **Auto** | Acto administrativo de seguimiento; tiene fecha de ejecutoria. |
| **SAN** | Proceso sancionatorio ambiental (estados en `estados_san`). |
| **ANLA** | Autoridad Nacional de Licencias Ambientales; “cantidad validada ANLA” en Indicadores. |
| **DIVIPOLA** | División político-administrativa de Colombia (códigos DANE de departamentos y municipios). |
| **CTM12** | MAGNA-SIRGAS Origen Nacional (EPSG:9377), sistema de las coordenadas de los mecanismos. |
| **Lote** | Una ejecución de la importación; permite reportar y revertir lo que insertó. |
| **Marcas** | Textos originales del Excel que no eran valores, conservados en jsonb. |
| **Sin determinar** | Resultado de un cálculo al que le falta un dato (en la base es `null`). |
